M5StickPomodoro

Firmware __VERSION__ · GitHub · Releases · Supported models & porting

A standalone, battery-friendly Pomodoro timer for the M5StickC Plus and the original M5StickC. You control it mostly by how the device is placed: face down pauses, standing it on its end shows a big countdown bar, a tap on the table shows the time.

Install from the browser

Your browser cannot talk to USB devices. Open this page in Chrome or Edge on a computer. Serial access needs a secure page (https).
  1. Connect the M5Stick over USB and switch it on (the port only exists while it is on).
  2. Press Connect and pick the port with usbserial in its name.
  3. Press Install and wait. The device restarts by itself when the install is done.

Updating keeps your saved settings. One firmware fits every supported model; the board is detected at boot.

macOS: if the port is busy or nothing connects, run killall scrod in Terminal (the VoiceOver braille service grabs new USB serial ports) and close any other program that has the port open.
