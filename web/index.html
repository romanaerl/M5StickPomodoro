M5StickPomodoro

Firmware __VERSION__ · source and documentation

A battery-friendly Pomodoro timer you control by how the device is placed. Install it on your M5Stick right from this page: nothing to download, no addresses to type.

Your browser cannot talk to USB devices. Open this page in Chrome or Edge on a computer. Serial access needs a secure page (https).
  1. Connect the M5Stick over USB and switch it on (the port only exists while it is on).
  2. Press Connect above and pick the port with usbserial in its name.
  3. Press Install and wait. The device restarts by itself when the install is done.

Updating keeps your saved settings (session lengths, sound, tap). The device is identified automatically; one firmware fits every supported model.

macOS: the port is busy or nothing connects? The VoiceOver braille service grabs new USB serial ports. Run killall scrod in Terminal, then press Connect again. Also close any other program that has the port open (a serial monitor, another browser tab).

Other ways to flash

Download the single-file image from the latest release and write it at offset 0x0 with esptool.py --chip esp32 write_flash 0x0 M5StickPomodoro-vX.Y.Z.bin, or build from source with scripts/flash.sh. Writing the single-file image resets the saved settings.
